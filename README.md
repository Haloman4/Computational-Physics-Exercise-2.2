# Computational-Physics-Exercise-2.2

This code is the answer to exercise 2.2 of Mark Newman's Computational Physics problems. It asks the user for an input of the orbital period in minutes, and returns the required height of the orbit. Also, I added my own code to show simple images of the 90 minute and 24 hour orbits, as well as simple code to show the minimum period time in minutes for a circular orbit.
